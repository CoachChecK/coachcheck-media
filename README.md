# coachcheck-media

Public hosting for **final, approved** CoachChecK social assets, so scheduling tools (Buffer) can fetch them by URL.

Served at https://coachcheck.github.io/coachcheck-media/

## Rules
- Final, approved assets only. Never drafts, previews, work in progress or anything not yet cleared for posting.
- Nothing sensitive: no personal data, no minors, no vendor data, no internal documents, no secrets.
- Brand rules apply (no league or school marks, no prices, no "confidence", no injury claims).
- Files are added on or shortly before their posting day. Layout: `rr/<post date>-<issue>/`.
- Source of record and review notes live in the private ops repo (`brand/rr-social/`).
